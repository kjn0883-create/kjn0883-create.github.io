WaxPocket Uploader

A private upload tool for the WaxPocket YouTube channel (https://www.youtube.com/@waxpocket).
WaxPocket Uploader uses YouTube API Services.

Privacy Policy  |  Terms of Service  (both on this page, below)


PRIVACY POLICY
Last updated: November 18, 2026

1. Who uses this tool
WaxPocket Uploader is used only by the owner of the WaxPocket YouTube channel to upload and schedule the
channel's own music playlist videos. It has no other users.

2. YouTube API Services
This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service
(https://www.youtube.com/t/terms). Google's handling of data is described in the Google Privacy Policy
(https://policies.google.com/privacy).

3. What data is accessed
With the channel owner's permission (Google sign-in, scopes https://www.googleapis.com/auth/youtube and https://www.googleapis.com/auth/youtube.force-ssl), the tool:
- uploads video files and sets title, description, tags, category, language, publish time and thumbnail;
- adds the video to a playlist on the same channel;
- sets translated titles and descriptions;
- manages live broadcasts on the same channel and posts one comment from the channel on its own new videos;
- reads the channel ID to confirm it is the WaxPocket channel, and reads the processing status of its own uploads.
It does not read other users' comments, subscribers, analytics or any other user's data.

4. What data is stored, and where
- An OAuth access/refresh token, stored only on the channel owner's own computer (file permissions: owner only).
- The ID of each uploaded video, stored in a local text file.
No data is sent to any server other than Google/YouTube. No data is sold, shared or used for advertising.
No cookies or tracking are used.

5. Data deletion and revoking access
- Access can be revoked at any time at https://myaccount.google.com/permissions
  (remove "WaxPocket Uploader"), or from the Google security settings page.
- When access is revoked, the locally stored token is deleted within 7 days, and no API data is kept.
- Locally stored YouTube API data (video IDs, status) is refreshed or deleted within 30 days, as required by
  the YouTube API Services Developer Policies.
- To request deletion of any stored data, contact the channel owner via https://www.youtube.com/@waxpocket.

6. Changes
Changes to this policy will be posted on this page with a new "Last updated" date.
